## 一、能力总览（已完成）

| 域 | 关键能力 |
| --- | --- |
| 办公助手 | 多轮会话、SSE 流式、停止生成、自动标题、按登录用户隔离；有图走视觉（最多 4 张）、无图走工具编排 |
| 助手工具 | 日程查询 / 日程解析草稿 / 周报草稿；登录安全分析、操作健康分析；工作流待办；预注册图表查询；失败会提示并再给一轮纠错 |
| 发图看图 | 上传或粘贴图片；本机/内网文件转 data URI 并发模型前压缩；看图 token 落库；工作流审批建议 / 风险预判也可带图片附件 |
| 业务页 AI | 多语言翻译、Cron 生成、代码生成列推断、登录/操作日志分析（各页独立按钮权限） |
| 工作流 AI | 自然语言生成流程、审批建议、流程体检、意图填单、实例摘要、风险预判、审批记录摘要 |
| 图表管道 | 白名单数据集（禁止 NL2SQL）：每日登录数、登录地域、操作日志多维统计；对话内组装折线/柱状/饼图 |
| 治理与成本 | 多级策略（user > role > tenant > global）、模型价格、用量统计/导出、配置检查（含 VisionModel 名）、Provider 探活；助手头栏展示 Token 与金额额度 |
| 模型接入 | OpenAI 兼容协议：`openai` / `deepseek` / `qwen` / `ollama`；供应商分项可配文本 `Model` 与 `VisionModel` |

## 二、全局办公助手

- **入口**：菜单 / 顶栏，权限 `ai:chat`；接口登录即可调，会话与消息只看本人。
- **会话**：列表、新建、重命名、删除（连同历史）、历史消息回灌（约 20 条）。
- **普通对话 / 流式对话**：同一套编排；流式事件 `delta` / `tool` / `done` / `error`，心跳保活。
- **工具编排**：最多多轮 function calling；工具中文名由后端 `Label` 维护；失败回灌纠错指令，全败且模型改直接回答时再强制一轮。历史消息可回看本轮工具成功/失败。
- **发图提问**：`imageUrls` 最多 4 张、单张 4MB；发给模型前超长边（约 1600）或体积过大才压成 JPEG，小图原样保留以免伤 OCR；未配 `VisionModel` 时友好提示。
- **额度**：头栏展示日/月 Token 与金额；任一触顶即拦截发送。对话场景可有分钟限流与默认月度 token 兜底。

### 助手已注册工具

| 工具 | 说明 | 权限 |
| --- | --- | --- |
| 日程查询 | 查当前用户日期范围内日程 | 无（仅本人数据） |
| 日程解析 | 口语转日程草稿，不落库 | 无 |
| 周报生成 | 按本周日程生成 Markdown 草稿 | 无 |
| 登录安全分析 | 登录日志安全报告 | `monitor:logininfor:ai` |
| 操作健康分析 | 操作日志健康报告 | `monitor:operlog:ai` |
| 待办查询 | 工作流待办 | 模块内校验 |
| 图表数据查询 | 只查预注册数据集 | 按数据集权限 |

## 六、治理、用量与接入

- **策略**：`global / tenant / role / user`，按场景限额（日/月 token、金额、并发）；`*` 为兜底场景。
- **价格**：按 Provider + 模型维护百万 token 单价，调用时算金额并落账。
- **用量**：全站 / 本租户 / 仅本人；按天、场景、用户汇总，可导出。看图轮次同样把 usage 写入助手消息。
- **健康**：配置检查（开关、地址、Key、**VisionModel 名称**）；探活场景 `health_check`。
- **接入**：`ai.json` 公共默认，`ai.Development.json` 本地覆盖（已 gitignore）；已预置 OpenAI、DeepSeek、通义、Ollama。Ollama 不强制云厂商 Key，跳过不兼容的 `stream_options`。

## 七、明确不做（当前版本）

- 自由 NL2SQL / 任意表查询 / 直接改库
- 知识库 RAG、文生图、改图
- 发图当轮同时调工具（看图后再查日程、出图需另开一轮纯文字）
- 助手代替业务页执行保存、审批、删除
- 业务用户在对话里自选模型（由管理员在配置中指定）
