## 二、流程设计能力

- **双设计器可互切**：
  - **LogicFlow（自由画布）**：图形化拖拽编排，节点顺序即流转，支持连线、节点属性面板、条件分支与并行网关。
  - **Simple（仿钉钉卡片流）**：纵向审批链形态，节点下方「+」插入、自动连线，属性在右侧抽屉配置；自带撤销/重做、缩放、节点完整性提示。两种模式保存的数据结构完全一致，可随时互切不丢配置。
- **驳回策略（审批节点）**：驳回发起人 / 驳回到上一审批节点 / 驳回到指定节点。指定节点须选择**当前节点之前**的审批节点；保存时缺目标会拦截。审批操作不另选目标，按节点配置回退。
- **AI 自然语言生成流程**：设计器「AI 生成」输入一句话业务描述，AI 返回完整流程草稿（节点/连线/审批人/签类型/条件）+ 推断表单字段，可一键采纳进设计器（详见《[操作手册](./manual.md)》§九）。
- **自动布局**：dagre 自动排版，条件分支 / 并行组无重叠。
- **撤销 / 重做**：作用于节点数据源快照。
- **流程示例模板**：请假 / 报销 / 金额条件 / 并行会签等一键注入，快速上手。
- **流程 JSON 导入导出**：查看、导入、复制流程定义 JSON，便于迁移与备份。

## 三、动态表单能力

- **JSON 驱动**：字段配置即生效，无需改码。
- **21 种控件**：单行/多行文本、数字、开关、下拉、单选、多选、评分、滑块、日期、日期时间、日期范围、时间、部门、人员、图片、文件、明细表，以及说明文字、分割线、分组标题等展示型控件。
- **明细表**：表单内嵌可增删行的子表（如报销明细），列支持文本 / 数字 / 日期 / 下拉 / 人员，数字列可配底部合计与行内公式。
- **字段联动**：联动显隐（等于 / 不等于 / 为空 / 包含 / 大于 / 小于等 9 种运算符）与联动计算（数字字段按公式自动重算，内置安全表达式引擎）。
- **系统字典绑定**：下拉 / 单选 / 多选可直接绑定系统字典作为选项来源，免手工维护。
- **字段级校验**：必填、长度、正则（手机号 / 邮箱 / 身份证 / 金额等常用预设一键选择）等规则。
- **表单模板库**：请假 / 报销 / 物品领用等内置模板，可复用。

> 规划中：级联下拉、富文本、签名。

## 四、流转与审批能力

| 能力                                 | 说明                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------- |
| 提交 / 通过 / 驳回 / 撤回 / 重新提交 | 驳回按节点策略：发起人 / 上一审批节点 / 指定历史审批节点；撤回未结束流程，重新提交回首节点重审（保留历史轨迹） |
| 转办                                 | 将待办转移给指定用户，节点不变                                          |
| 加签                                 | 当前节点追加审批人，新待办纳入完成判定                                  |
| 减签                                 | 移除当前节点某加签 / 会签待审批人                                       |
| 委托代审                             | 任务仍归属原审批人，仅记录代审人；代审人可代为通过 / 驳回，记录代审标识 |
| 催办                                 | 申请人发起，提醒当前审批人（限频，避免骚扰）                            |
| 批量审批                             | 待办列表一次性批量通过                                                  |
| 管理员干预                           | 终止 / 挂起 / 恢复 / 改派 / 跳转（含并行组内单节点跳转，不卡死）        |
| 审批人为空自动跳过                   | 节点无审批人时自动放行并留痕，不阻断流程                                |
| 运行态流程图高亮                     | 当前节点高亮、已完成节点标记、流转路径清晰可见                          |
| 审批进度时间线                       | 动作 / 操作人 / 意见 / 时间全记录（含自动跳过语义）                     |
| 操作审计日志                         | 按实例 / 动作检索的独立审计视图                                         |
| 评论 / 批注                          | 节点级评论                                                              |

### 多人审批（签类型）

- **或签**：一人通过即通过。
- **会签**：需全部审批人通过。
- **依次审批（顺序会签）**：按审批人顺序逐个审批，前一人审完才轮下一位，全部通过才推进，任一驳回则整节点驳回。
- **比例会签（Percent）**：多人同时激活，通过人数达到节点 `PassRatio`（如 0.6=60%）即推进节点，不要求全员一致，适合委员会 / 多人表决场景。

### 审批人来源（6 种）

| 来源       | 说明                                               |
| ---------- | -------------------------------------------------- |
| 指定用户   | 直接指定 userId                                    |
| 指定角色   | 按角色解析成员                                     |
| 指定部门   | 取部门下全部用户                                   |
| 表单字段   | 运行时从表单值动态解析审批人（如「部门经理」字段） |
| 部门负责人 | 解析部门 Leader                                    |
| 发起人主管 | 自动取发起人的直属上级                             |

> 兜底策略：当审批人最终解析为空时，可配置「自动通过」或「指定默认审批人」，避免流程卡死。

## 四-B、AI 智能能力

> 后端 `WfAiService` / `WfAiController`（`api/wf/ai/*`），依赖 `appsettings.json` 的 `AiOptions`（Enable / Endpoint / ApiKey / Model / Providers）。`Enable=false` 时前端所有 AI 入口自动隐藏，不影响现有流程功能。

| 能力             | 入口                    | 说明                                                                                                                                        |
| ---------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 自然语言生成流程 | 设计器「AI 生成」       | 一句话描述业务 → 返回完整流程草稿 + 推断表单字段，可采纳进设计器（temperature 0.2，结构稳定）                                               |
| 审批智能建议     | 待办详情「AI 建议」     | 结合节点/表单/流转路径生成审批参考意见，审批人可一键采纳，最终仍由人拍板；支持 `?regenerate=true` 重生成                                    |
| 审批自动摘要     | 审批动作后台自动        | 每次审批动作自动压缩为一句话摘要写入一条 `Action=0` 系统记录的 `AiSummary` 字段（落痕）；另提供实例级连贯摘要 `instance-summary` + 重新生成 |
| 流程体检         | 流程定义「AI 体检」     | 发布前合规性检查：缺结束节点/孤立节点、条件分支是否覆盖默认、审批人是否为空、并行汇聚配对等                                                 |
| 自然语言填单     | 发起页「AI 帮我填」     | 业务诉求文本自动抽取字段回填表单，确认即提交                                                                                                |
| AI 风险检查      | 待办详情「AI 风险检查」 | 基于节点+表单+路径研判风险等级/说明/处置建议，仅展示不影响流转（提示词 `risk-check.md`）                                                    |

## 五、分支与并行

- **条件网关**：根据表单字段 + 运算符 + 比较值自动选择分支，支持多分支与默认分支，可作流程首节点。
- **并行会签组 / 并行网关**：分叉节点并行激活多个分支，汇聚节点等待全部分支完成再继续；支持包容网关（条件不满足的分支视为已完成）。

---

## 六、流程版本管理

- **多版本共存**：同一流程可保留多个版本，现行版本唯一标识。
- **发布 / 设现行 / 回滚**：草稿转正式、切换现行版本、历史版本复制为新版（保留版本链）。
- **复制为独立流程**：整体复制，便于 A/B 试验。
- **版本对比（diff）**：选择基准版本与对比版本，按节点对齐比较类型、审批人、签类型、并行组等关键字段，标色展示新增 / 移除 / 修改（前端拉取两版定义后在浏览器内计算差异，无后端专用接口）。

---

## 六-B、超时自动处理

- **节点级超时配置**：每个审批节点可独立设置「超时时长（小时）」与「超时动作」。
- **超时动作**（4 选 1）：不处理（默认） / 自动通过 / 自动驳回 / 转交指定用户（若未指定转交人则退化为自动通过，不卡流程）。
- **后台定时驱动**：独立定时任务 `Job_WfTimeoutAutoProcess`（默认每 5 分钟按租户扫描）捞取 `DeadlineTime` 已过的待办，按节点配置自动执行并写审批记录 + 通知，无需人工介入。

## 七、消息通知与集成

- **站内信 + 实时推送**：待办到达、审批通过 / 驳回、撤回、转办、加签、抄送知会等场景覆盖；异常不影响主流程。
- **未读标记与未读数**：待办 / 抄送支持已读未读状态。
- **Webhook 出站**：节点进入 / 离开事件以事务发件箱（Outbox）可靠登记，独立定时任务投递外部系统，失败自动重试，超限进入死信，不阻断主流程。

> 规划中（见 §十一 路线图 P1/P2）：邮件 / 短信、企业微信 / 钉钉 / 飞书应用消息、审批结果回写业务表。

## 九、多端支持

- **PC 管理端**（Vue3 + Element Plus）：流程设计、表单设计、发起、待办、已办、抄送、审批记录、数据面板、表单模板全套。
- **移动端**（uni-app）：发起、详情、待办、已办、抄送、我发起等核心能力。

## 十、技术亮点

- **事务一致性**：核心流转全部事务包裹，活动节点集为权威状态，高并发场景去重（或签多待办并发不重复分支）。
- **可观测**：完整审批动作留痕（含自动跳过、委托代审等语义化记录），运行态流程图与进度时间线一致。
- **开放集成**：权限点统一种子化并授权，Webhook 出站便于对接外部系统。
- **技术栈**：Vue3 + Vite + Element Plus / .NET + SqlSugar，复用 ZRAdmin 的权限、用户、部门体系，开箱即用。

## 十一、规划中能力路线图

标注「规划中」的能力当前版本尚未内置，均可作为**定制开发**提供。按优先级排序：

### P1（高优先，办公协同常用）

| 能力                                | 说明                                                               |
| ----------------------------------- | ------------------------------------------------------------------ |
| 子流程嵌套                          | 当前为单流程模型，支持在节点内调用子流程（§一 已注明为规划项）     |
| 审批结果回写业务表                  | 流程结束后按配置回写业务系统数据（如请假天数同步 HR）              |
| (P1) 企业微信 / 钉钉 / 飞书应用消息 | 移动端 IM 推送审批待办与结果（后端接口已具备，前端对接层可按需补） |

| 邮件 / 短信通知 | 审批前后邮件 / 短信触达（站外可达）                         |
